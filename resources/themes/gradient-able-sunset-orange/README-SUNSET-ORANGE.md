# Gradient Able — Sunset Orange preset

A separate warm orange palette for the existing Gradient Able Laravel theme. This is a theme-layer update, not a complete Laravel project.

## Palette
- Sunset Orange primary: `#FF6B35`
- Warm orange hover: `#FF8A5B`
- Deep charcoal: `#171311`
- Warm charcoal surface: `#292321`
- Light page background: `#F3F4F6`
- White cards: `#FFFFFF`

## Use
Replace the matching theme files in your installed theme with the files in this archive, then rebuild your Vite assets using your project's usual build command. Keep a backup of your current files first.

This palette is separate from the 8 Group black-and-gold preset.
